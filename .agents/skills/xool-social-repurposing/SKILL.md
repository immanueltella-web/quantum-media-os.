# XOOL Social Repurposing

Extend proven ideas beyond Pinterest while preserving the original commercial insight.

## Principle
Do not copy-paste the same post everywhere. Adapt the idea to each platform's native behaviour, audience expectation, and format.

## Inputs
Use:
- source Pinterest concept or winning asset,
- brand voice,
- offer,
- proof/compliance rules,
- target platform,
- objective,
- relevant performance learnings.

## Platform guidance
- LinkedIn: point of view, commercial insight, case-study logic, founder/operator credibility.
- Threads: conversational observations, short useful sequences, questions, contrarian-but-supported insights.
- X: concise arguments, data points, strong hooks, useful threads.
- Instagram/Facebook: visual-led storytelling, proof, product/service relevance, community response.
- Short-form video: hook -> tension/problem -> insight/demo -> CTA.

## Output per adaptation
```text
Source idea:
Target platform:
Objective:
Hook:
Native format:
Final copy/script:
Visual requirement:
CTA:
What changed from Pinterest and why:
```

Save outputs under platform-specific subfolders within `outputs/`.

## Rule
A Pinterest winner is a signal, not permission to claim the same result will occur elsewhere. Treat each adaptation as a new test.
