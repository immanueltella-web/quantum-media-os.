# XOOL Creative Studio

Create visuals that look native to Pinterest while serving a measurable commercial goal.

## Modes
- Product: feature a specific real product using supplied source assets.
- Lifestyle: place a verified product/service into a relevant use context.
- Editorial: inspiration, how-to, list, comparison, or trend-led creative.
- Carousel: multi-frame story designed around a clear progression.
- Infographic: useful information with strong hierarchy and save value.
- Concept: original campaign visual where no real product fidelity is required.

## Source-of-truth rules
For real client products, packaging, people, logos, or regulated text:
- use supplied source assets,
- preserve identity, shape, labels, colours and logos,
- never fabricate endorsements or product features,
- use separate typesetting when exact legal/price/URL text is business-critical.

## Pinterest principles
- Design for mobile-first vertical discovery.
- Make the promise visible quickly.
- Use visual specificity rather than generic stock aesthetics.
- Build around a real planning moment, problem, transformation, product use, or aspiration.
- Favour multiple distinct hypotheses over trivial colour swaps.

## QA
Check:
- brand consistency,
- legibility,
- accurate product representation,
- no invented claims,
- correct ratio,
- strong visual hierarchy,
- clear relation between creative and landing page,
- reusable test label.

## Output
Save briefs, prompt logs, source references, QA notes, and final asset references under `outputs/creatives/`.
