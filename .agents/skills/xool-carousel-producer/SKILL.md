# XOOL Carousel Producer

Create multi-frame assets that earn attention by progressing through one clear idea.

## Choose a story arc
Examples:
- Hook -> problem -> insight -> solution -> CTA
- Desired outcome -> obstacles -> method -> proof -> next step
- Myth -> truth -> evidence -> application -> CTA
- Before -> turning point -> process -> after -> takeaway
- Checklist -> examples -> prioritisation -> action

## Slide plan
For every slide define:
```text
Slide number:
Job of slide:
Exact headline/copy:
Visual concept:
Source asset if required:
Continuity cue:
```

## Rules
- Each slide must advance the story; avoid disconnected quote cards.
- Keep copy scannable on mobile.
- Preserve real product/brand elements.
- Use consistent visual language across frames.
- Make the final action explicit: save, click, shop, learn, book, compare, or another agreed objective.
- If exact small legal copy or prices are required, prefer deterministic typesetting rather than relying on generated image text.

## Output
Save slide plan, creative brief, asset references, QA notes, and ordered final asset references under `outputs/creatives/carousels/`.
