# XOOL Pinterest SEO

Build discoverability around how people search, plan, compare, and save on Pinterest.

## Inputs
Read brand, audience, offer, Pinterest strategy, performance history, and any available search/trend evidence.

## Research principles
- Prefer specific commercial and planning-intent themes over broad vanity keywords.
- Separate evergreen, seasonal, problem-led, product-led, and occasion-led intent.
- Treat search-volume estimates carefully; record source and date where available.
- Do not keyword-stuff. Titles and descriptions must still read naturally.

## Output files
Create or update:
- `context/keyword-map.md`
- `context/board-map.md`

## Keyword map format
```text
# Pinterest Keyword Map

| Cluster | Primary keyword | Related intent | Funnel stage | Priority | Evidence | Content angle |
|---|---|---|---|---|---|---|
```

## Board map format
```text
# Pinterest Board Map

| Board | Audience intent | Core keywords | Content types | Commercial role | Priority |
|---|---|---|---|---|---|
```

## On-Pin guidance
For each planned Pin, provide:
- one primary keyword theme,
- natural title,
- natural description,
- board destination,
- landing-page destination,
- image/video concept aligned to the query,
- funnel objective.

## Learning loop
Use performance data to update keyword priority based on outbound clicks, saves, conversions, CPA, revenue, and ROAS where available—not impressions alone.
