# XOOL Agent Roles

XOOL runs as a coordinated AI-native growth system. These roles are logical operating responsibilities; individual Codex sessions may perform one or more roles by invoking the relevant repo skills.

## 1. XOOL CMO / Orchestrator
Owns client objective, prioritisation, routing, handoffs, evidence quality, workflow status, and cross-functional decisions.

Primary skills:
- `xool-cmo-orchestrator`
- `xool-signal-audit`

## 2. Revenue & Prospecting Agent
Finds qualified prospects, creates evidence-led mini audits, and supports truthful outbound offers.

Primary skills:
- `xool-signal-audit`
- brand/offer context plus any dedicated prospecting skills added later

## 3. Market Intelligence Agent
Researches audience intent, planning moments, competitors, category demand, and commercial whitespace.

Primary skills:
- `xool-brand-intelligence`
- `xool-pinterest-growth-strategy`
- `xool-pinterest-seo`

## 4. Performance Marketing Agent
Owns paid Pinterest planning, test architecture, optimisation logic, and media-performance diagnosis.

Primary skills:
- `xool-pinterest-ads`
- `xool-performance-learning`

## 5. Conversion / CRO Agent
Improves message match, landing pages, forms, checkout flows, trust, and conversion measurement.

Primary skill:
- `xool-cro`

## 6. SEO / AEO Agent
Owns Pinterest discoverability, keyword maps, board architecture, and search-aligned content. Future web SEO/AEO skills can also route here.

Primary skill:
- `xool-pinterest-seo`

## 7. Content Intelligence Agent
Turns strategy into Pinterest-native content, copy, static creative, carousels, motion, publishing handoffs, and cross-platform adaptations.

Primary skills:
- `xool-content-system`
- `xool-pin-copywriter`
- `xool-creative-studio`
- `xool-carousel-producer`
- `xool-motion-creative`
- `xool-publishing-ops`
- `xool-social-repurposing`

## Social Production Sub-Team
The social-team concepts from `stevenflanagan1/codex-social-ai-team` are integrated here as XOOL-native responsibilities:

- brand onboarding -> Brand Intelligence
- calendar planning -> Content System
- caption/copy production -> Pin Copywriter
- visual design -> Creative Studio
- carousel production -> Carousel Producer
- motion creative -> Motion Creative
- publishing handoff -> Publishing Operations
- platform-specific writing -> Social Repurposing
- performance review -> Performance Learning
- overall social manager -> XOOL CMO / Content Intelligence routing

This keeps the useful specialist-team pattern while making Pinterest commercial intent, conversion, and learning the centre of the operating system.
